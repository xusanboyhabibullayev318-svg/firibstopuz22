NETLIFY (важно для текущего сайта):
1. Загрузите всё содержимое папки проекта в тот GitHub-репозиторий, который подключён к Netlify.
2. Дождитесь Deploy published.
3. ОБЯЗАТЕЛЬНО отключите пароль сайта: Site configuration → Access control → Visitor access / Password protection → Off.
   Иначе /api/health и /api/news отдают HTML-страницу входа (HTTP 401), а лента новостей не работает.
4. Откройте https://ВАШ-САЙТ.netlify.app/api/health — должен появиться JSON с ok: true (не Login Redirect).
5. Откройте https://ВАШ-САЙТ.netlify.app/api/news — должен появиться JSON с items и sources.
6. Вернитесь в FiribStop и нажмите Ctrl+Shift+R.

Теперь Netlify Functions обслуживают /api/news и /api/health; для новостей не нужен отдельный Render-сервер и не требуется токен. Каждый RSS-источник может временно быть недоступен, состояние показывается в sources.

=== REAL THREAT RADAR (2.7.9) ===

The global radar uses Cloudflare Radar API. It does not generate fake attacks or fake counters.

For Netlify:
1. In Cloudflare, create an API token with Account -> Radar -> Read permission.
2. In Netlify, open Site configuration -> Environment variables.
3. Add CLOUDFLARE_RADAR_API_TOKEN with the token value.
4. Trigger a new deploy. Never put this token in app.js, index.html, or a public repository.
5. Open /api/radar-data to inspect the JSON response; status should be "ok" or "partial".

Optional: own-site firewall events require a domain proxied by Cloudflare, plus CLOUDFLARE_ZONE_ID and CLOUDFLARE_ZONE_API_TOKEN with the appropriate read permission. A *.netlify.app subdomain alone cannot provide Cloudflare zone firewall events.

The Radar page shows aggregate network-layer attack statistics for the last 24 hours, refreshed approximately every 5 minutes. It is not a packet-by-packet feed, does not prove attacks against Uzbekistan, and cannot provide telemetry for networks Cloudflare does not observe. Until the API token is configured, the page explicitly shows that data is not configured and does not fabricate values.

Node hosting (e.g. Render) uses the same CLOUDFLARE_RADAR_API_TOKEN environment variable. Netlify deploys the serverless functions in netlify/functions.
